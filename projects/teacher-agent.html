中学教师教学评估与改进智能体Teaching Evaluation & Improvement Agent

课题组的课程教学资源库，原来的界面是照技术视角搭的。这个项目把它按老师的一天重做：从上传一节课的录音，到拿到一份能直接拿去评课的报告。 My lab's lesson-resource system was built around its data model. This project rebuilds it around a teacher's day: from uploading a lesson recording to holding a report you can take straight into a review meeting.

The Starting Point

这套系统原来是什么样What the system looked like

课题组的课程教学资源库原本是照技术视角搭的：数据项齐全，但老师进来不知道该点哪儿。The lab's lesson-resource system was built around its data model: complete on paper, opaque to a teacher opening it.

问题Problem 表现Symptom
入口冗余Cluttered entry首页堆着统计卡片、图表和版本更新记录，没有"下一步做什么"Statistics, charts and changelogs where the next action should be
术语技术化Technical jargon语料、编码体系、阶段频次、编码点阵——老师看不懂，也没法直接用Corpus, coding scheme, phase frequency — unreadable to teachers

Redesign

六个改动Six changes

核心只有一句：把系统从"功能堆砌"改成"老师的一天怎么过"。One idea underneath all of them: organise the system around a teacher's day, not around the feature list.

用老师的话重命名Speak the teacher's language

语料 → 课例corpus → lesson

语料改叫课例，转录文本改叫课堂实录，编码分析改叫课堂评价，分析报告改叫评课报告。名字一换，老师才知道这是自己的东西。Corpus became lesson, transcript became class record, coding became evaluation, analysis report became review report. Renaming is what makes it feel like theirs.

首页从数据大屏改成工作台A workbench, not a dashboard

3 个动作 + 待办3 actions + to-dos

只留上传课例、新建课例、批量导入三个动作，下面是最近五节课和"哪节课的报告出来了"。统计图表、版本记录全部撤掉。Only three actions — upload, create, bulk import — then the last five lessons and what needs attention. Charts and changelogs are gone.

个人空间和公共空间分开Mine vs. shared

我的课例 / 公共资源My lessons / shared

我的课例按状态管：待转录、转录中、待评课、已完成。公共资源按教研组、学校、区域、平台精选分四层，默认只露脱敏后的报告摘要。Personal lessons tracked by state; shared resources in four tiers, showing only sanitised summaries by default.

报告按评课的场景重做A report made for review

一页结论 · 两页证据One page of verdict, two of evidence

第一页给总体评价、课堂亮点、待改进项和五个关键指标；第二页每条结论挂一段课堂实录，教师可以批注、可以改分；第三页数据附录可选。导出 PDF 或 Word，直接进教研组。Page one: verdict, highlights, what to fix, five indicators. Page two: each conclusion pinned to a transcript excerpt, annotatable and re-scorable. Page three: optional data appendix. Export to PDF or Word.

批量导入Bulk import

一节课 = 多个文件one lesson, many files

录音、视频、教案、Excel 记录可以一起传，按文件名自动分组，每组就是一个课例；学科、年级、教材批量填，剩下的等它跑完。Audio, video, lesson plan and spreadsheets in one go; files group themselves by name into lessons, with subject, grade and textbook filled in bulk.

教研助手能共创，不只是生成An assistant you can work with

PPT · 教案 · 逐字稿slides · plans · scripts

生成 PPT、教案和逐字稿时，可以先挑几个优秀课例当参考，让模型提取它们的结构、互动和语言风格，再按自己的习惯改；改完还能接着对话微调。When generating slides, plans or scripts, a teacher can first pick a few strong lessons as references, let the model lift their structure, interaction and tone, then adjust — and keep refining by talking to it.

My Contribution

我负责的部分What I owned

这个项目由课题组共同完成，我主要负责把"评课"这件事翻译成模型能执行的任务，以及把界面画出来。A team effort; my part was translating "lesson review" into a task a model can run, and drawing the interface.

任务拆解Task decomposition

一句需求 → 四个环节one ask → four steps

把"评一节课"拆成材料解析、维度打分、证据定位、建议生成，每一步都有明确的输入输出，单独拿出来也能验。Broke "evaluate a lesson" into parsing, scoring, evidence and suggestions — each with defined inputs and a way to check it alone.

评价维度Rubric

4 个维度4 dimensions

目标清晰度、任务设计、师生互动、评价一致性。每个维度都要求指向实录里的具体时间点，不给没有出处的分。Clarity of objectives, task design, teacher–student interaction, alignment of assessment — each one must point at a timestamp.

Prompt 与输出格式Prompt and output format

维度 · 规则 · 格式dimensions · rules · format

三层结构：评什么、什么算好、怎么呈现。字段固定下来，同一节课跑两次才不会给出两套说法。Three layers — what is judged, what counts as good, how it is presented. Fixed fields are what keep two runs from telling two stories.

界面线框Wireframes

7 屏 · 三种角色7 screens · 3 roles

教师、教研人员、管理员共用一套数据，界面按角色渲染：教师看"我的课和待办"，研究者看"研究主题和可引用资源"。Teachers, researchers and admins share one dataset; the interface renders by role — my lessons for teachers, topics and citable resources for researchers.

Flow

一节课走完这条链路One lesson through the pipeline

下面这条链路对应线框里的页面顺序，也是和团队讨论任务边界时用的同一张图。This chain matches the page order in the wireframes — the same diagram used to scope the work with the team.

01
提交材料Submit
教学设计、课堂实录、作业或反思，单节提交或批量导入。Lesson plan, recording, assignments or reflection — single or batch.
02
结构化解析Parse
把非结构化材料切成可定位的片段，作为后面判断的证据来源。Split materials into locatable segments later judgements can cite.
03
多维评价Evaluate
按预设维度与判定规则逐项打分，要求给出对应证据。Score each dimension against written rules, with evidence required.
04
生成报告Report
组织成教师能读的报告，而不是一堆术语。Assemble scores and evidence into something a teacher can read.
05
改进与沉淀Improve
输出可执行的改课建议，课例归入教研主题供后续比较。Output actionable changes and file the lesson under a research theme.
